# SplitBill PRD

## Overview

SplitBill is an AI-powered restaurant bill splitting web app. Users upload a receipt, review extracted items, assign dishes to friends, and generate a mathematically correct split including GST, service charge, and discounts.

## Core Features

1. Upload receipt.
2. Review extracted bill.
3. Add friends.
4. Assign items.
5. Calculate final split.
6. Copy UPI / Share summary.

## Out of Scope

* Authentication.
* Database.
* Payment gateway.
* History.
* Notifications.

## User Flow

Upload → Review → People → Assign → Split Result
